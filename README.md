# Service Provider Portal (Mwafq)

Arabic-first (RTL) / English front-end for Mwafq service providers.
Starter project: Pulse theme, app shell, reusable components, and two sample
screens (Today, Reservations table). See **CLAUDE.md** for the design map,
conventions and the handover TODO list.

```bash
cp .env.example .env   # set VITE_API_BASE_URL
npm install
npm run dev
```
